# AQA Frontend Tests — Automation Exercise

Проект с UI-автотестами для сайта [automationexercise.com](https://automationexercise.com), написанными на Playwright с использованием паттерна Page Object Model.

## Что делает проект

Покрывает автотестами ключевые страницы сайта:
- **Home** — главная страница
- **Login** — форма авторизации
- **Products** — страница каталога товаров

Для каждой страницы есть отдельный layout-тест (проверка, что все ключевые элементы отображаются) и функциональные тесты (проверка поведения при взаимодействии).

## Технологии

- **Playwright** — фреймворк для UI-автотестов
- **TypeScript**
- **POM (Page Object Model)** — структура с классами-страницами в `pages/`

## Структура проекта

```
pages/       — классы страниц: локаторы элементов и методы действий/проверок
tests/       — тестовые сценарии, использующие классы из pages/
.env         — тестовые данные (email/пароль для логина), не хранится в git
```

## Как запустить

1. Установить зависимости:
   ```
   npm install
   ```

2. Создать файл `.env` в корне проекта:
   ```
   TEST_EMAIL=test@test.com
   TEST_PASSWORD=wrongpassword
   ```

3. Запустить все тесты:
   ```
   npx playwright test
   ```

4. Запустить тесты конкретной страницы, например:
   ```
   npx playwright test tests/login.spec.ts
   ```

5. Запустить в UI Mode (наглядный просмотр шагов):
   ```
   npx playwright test --ui
   ```
